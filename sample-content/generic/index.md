# Welcome

This is a **generic website**: the folder this site lives in is served as web
pages, one page per Markdown file, with nothing assumed about structure or
purpose.

The sample has exactly two pages — this one (`index.md`) and
[Anatomy](%base_url%/anatomy), which explains the file layout, the page
header keys and the theming conventions. Replace both with your own content.

[If you just want a ready-made site, the wizard's Blog, Team site and
Documentation options come with structure and in-browser editing. Generic is
the blank slate.]
